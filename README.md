# TechSphere 🌐

## 📌 Project Overview
TechSphere is a modern e-commerce web application designed to provide users with a smooth, secure, and user-friendly online shopping experience. The platform allows customers to browse a wide range of tech products such as smartphones, headphones, tablets, smarthwatces, and TVs and add them to a cart, and complete purchases through a secure checkout system.
The goal of this project is to create a responsive and intuitive system that simplifies online shopping while ensuring efficient management of products, users, and orders.

---
## 🎯 Key Features

### 🛍️ Customer Features
- Browse products by category
- Search for products (by name/type)
- Add and remove items from cart
- Secure checkout process
- View order history
- User account management

### 🛠️ Admin Features
- Manage products (add, edit, delete)
- Update stock levels
- Manage customer accounts
- View and process orders
- Track revenue and analytics

---

## 🏗️ Tech Stack

### Frontend

### Backend
- Node.js
- Express.js

### Database
- Supabase (PostgreSQL)

## 👥 Target Audience
TechSphere is designed for users aged 18–65 who are interested in purchasing the latest technology products online.
